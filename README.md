# Hemanth Sharma — Portfolio

Personal portfolio site built with Next.js, Tailwind CSS and Framer Motion, deployed as a static site on GitHub Pages.

**Live:** https://hemanths933.github.io/

## Develop

```bash
npm install
npm run dev
```

All content lives in [`lib/data.ts`](lib/data.ts).

## Deploy

Pushing to `main` builds a static export (`npm run build` → `out/`) and publishes it via GitHub Actions.
